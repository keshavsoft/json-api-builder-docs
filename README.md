## How to Run Locally

You can preview the website immediately with any static server:

```bash
# Navigate to this folder
cd json-api-builder-docs

# Using npx serve
npx serve .

# Or using Python
python -m http.server 8080
```

Then open `http://localhost:3000` (or `8080`) in your browser.
